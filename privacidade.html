Política de privacidade — app “Luna”

Última atualização: 20/10/2026

O que é o app

“Luna” é um aplicativo pessoal da Luna Reeves (página inicial). Ele serve só para que a Luna use a própria conta Google, lunareverb@gmail.com, no trabalho dela.

Quais dados o app acessa

O app acessa apenas o Google Drive, o Google Docs e o Google Planilhas da conta lunareverb@gmail.com, para buscar, ler, criar e editar os arquivos de trabalho da própria Luna. Ele não acessa contas, arquivos ou dados de outras pessoas.

Como os dados são usados

Os dados da conta são usados somente para executar esse trabalho. A credencial de acesso fica guardada apenas no computador da Luna.

Compartilhamento

O app não vende, não aluga e não compartilha dados com terceiros. Não há publicidade, análise de comportamento nem coleta de dados de visitantes.

Retenção e revogação

Os dados permanecem na própria conta Google. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Contato

Dúvidas sobre esta política: lunareverb@gmail.com.
